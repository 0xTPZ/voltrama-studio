# Voltrama Components

O Community expõe apenas fichas públicas curadas. Cada ficha separa valores de referência, dados medidos e estado de verificação. Quando fabricante, encapsulamento, pinagem ou datasheet não foram confirmados, o campo permanece pendente.

O inventário pessoal é uma função privada do Studio e não é lido pelo build estático. A associação de uma peça a um projeto representa planejamento de BOM; não reduz automaticamente o estoque. Não existe selo universal de componente aprovado.

Nesta primeira fatia pública, `#components` contém exemplos demonstrativos com verificação pendente e sem datasheets afirmados. Contribuição pública automática e sincronização com KiCad permanecem planejadas.
