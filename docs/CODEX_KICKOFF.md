# Codex kickoff — M0-001

Esta missão estabelece a fundação pública do Voltrama Studio. O código público contém somente decisões e artefatos compartilháveis. Contexto operacional fica no repositório privado.

## Critérios de conclusão

1. Workspace separado em `voltrama-studio`, `voltrama-internal` e `workspace`.
2. Interface navegável, responsiva e acessível em escopo inicial.
3. Repositório público MIT e repositório interno privado verificados antes do primeiro push privado.
4. Teste smoke executado.

## Não objetivos

Não implementar ainda o editor elétrico, solver, validação SPICE, sincronização com serviços externos ou catálogo comunitário.
