# Voltrama Studio

Voltrama Studio é uma fundação open source para engenharia eletrônica: projetos, documentação, componentes e futuras integrações com ferramentas maduras de EDA.

> M0-001 entrega uma interface navegável e a arquitetura inicial. Editor elétrico, simulação e geração de artefatos ainda não estão implementados.

## Estado atual

- Interface estática responsiva em HTML, CSS e JavaScript sem dependências externas.
- Navegação entre visão geral, workspace, biblioteca e comunidade usando hash routing.
- Identidade visual original baseada em trilhas de circuito e nós de conexão.
- Contratos de integração documentados para KiCad, ngspice e designElectronics.

## Executar localmente

Abra `src/index.html` em um navegador moderno ou sirva a pasta `src/` com qualquer servidor HTTP estático.

## Princípios

Clareza antes de automação, interoperabilidade antes de lock-in, rastreabilidade antes de confiança implícita e acessibilidade desde o primeiro componente.
